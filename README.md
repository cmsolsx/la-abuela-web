# La Abuela Verdulería y Frutería

Sitio web Bootstrap 5 listo para GitHub Pages.

## Estructura

- `index.html`: página principal
- `productos.html`: galería de productos
- `recetas.html`: recetas saludables
- `contacto.html`: ubicación y WhatsApp
- `css/estilos.css`: estilos del sitio
- `js/main.js`: comportamiento básico
- `img/`: imágenes del proyecto

## Publicación en GitHub Pages

1. Crear repositorio público llamado `la-abuela-web`.
2. Subir todos estos archivos y carpetas.
3. Ir a Settings > Pages.
4. Seleccionar Deploy from a branch.
5. Branch: main. Folder: /root.
6. Guardar y esperar el enlace público.
